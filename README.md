# 应用广告拦截

GKD 安卓广告拦截订阅，毫秒级响应，精准不误触。

## 订阅地址
```
https://github.com/webcstx/doubao-quick-tools/releases/download/v3.0.1/GKD-subscription.json3
```

## 功能
- 🚀 毫秒级自动跳过开屏广告
- 🎯 精准拦截，不误触正常按钮
- 🛡️ 排除权限弹窗、通知弹窗等
- ⚡ 快速查询模式
