安装根证书

安卓：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书
Windows：双击 rootCA.crt，存储位置选「受信任的根证书颁发机构」
iOS：用描述文件安装后，到「设置 → 通用 → 关于本机 → 证书信任设置」里开启完全信任
浏览器单独信任：导入到浏览器的「受信任的根证书」列表即可

在服务器上启用 HTTPS

把证书文件传到服务器（示例路径 /etc/ssl/webcat/），再按服务器类型套用配置。
server {
    listen 443 ssl;
    server_name webcat.bbroot.com;

    ssl_certificate     /etc/ssl/webcat/fullchain.pem;
    ssl_certificate_key /etc/ssl/webcat/cert.key;
    ssl_protocols       TLSv1.2 TLSv1.3;

    location / {
        root  /var/www/html;
        index index.html;
    }
}

server {
    listen 80;
    server_name webcat.bbroot.com;
    return 301 https://$host$request_uri;
}
<VirtualHost *:443>
  ServerName webcat.bbroot.com
  SSLEngine on
  SSLCertificateFile    /etc/ssl/webcat/fullchain.pem
  SSLCertificateKeyFile /etc/ssl/webcat/cert.key
  DocumentRoot /var/www/html
</VirtualHost>
改完先自检再重载：nginx -t && nginx -s reload；apachectl configtest && systemctl reload httpd。
