安装位置：安卓「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」；Windows 选「受信任的根证书颁发机构」；iOS 用描述文件安装后到「关于本机 → 证书信任设置」里开启。
CAA 是告诉公共 CA「哪些 CA 可以给这个域名签发证书」的授权记录，只有公共 CA 在签发前会查它。本站的自建 CA 在浏览器本地生成，不查 CAA。
如果这个域名同时托管在 GitHub Pages，它的证书由 Let's Encrypt 签发，必须放行 letsencrypt.org，否则到期续签会被拦下。
注意：CAA 记录要写在根域（如 bbroot.com），CA 会从子域逐级向上找最近的记录；已经设成 CNAME 的域名不能再挂别的记录，所以不能写在已经设成 CNAME 的那个子域上。
主机记录根域（如 bbroot.com），不要写在 CNAME 域名上
记录类型CAA
记录值0 issue "letsencrypt.org"
值固定为标准写法，不随机、不重新生成。有的面板把 CAA 拆成三格：Flags 填 0、Tag 填 issue、Value 填 letsencrypt.org（Value 里不要带引号）。
注意 0 issue ";" 的含义是「不允许任何 CA」，不是放行全部。
