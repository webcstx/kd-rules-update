自由签发

由本站自建的根证书（自由签发 CA）为你的域名签发证书，有效期可自定义。先在设备里安装一次根证书，之后签发的证书就会被系统信任。签发机构标识为 https://webcat.bbroot.com/分发证书。

支持通配符（如 *.bbroot.com）与 IP 地址，会自动写入证书的 SAN 扩展。
当前设置：90 天
浏览器本地生成，2048 位一般需要 1 到 3 秒。
首次使用会在这台设备生成一张有效期 20 年的根证书，保存在本机浏览器里，重复使用同一张。
根证书名称CN=https://webcat.bbroot.com/分发证书, O=自由签发
SHA-256 指纹—
安装位置：安卓「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」；Windows 选「受信任的根证书颁发机构」；iOS 用描述文件安装后到「关于本机 → 证书信任设置」里开启。
CAA 是告诉公共 CA「哪些 CA 可以给这个域名签发证书」的授权记录，只有公共 CA 在签发前会查它。本站的自建 CA 在浏览器本地签发，不查 CAA。
如果这个域名同时托管在 GitHub Pages，它的证书由 Let's Encrypt 签发，必须放行 letsencrypt.org，否则到期续签会被拦下。
注意：CAA 记录要写在根域（如 bbroot.com），CA 会从子域逐级向上找最近的记录；已经设成 CNAME 的域名不能再挂别的记录，所以不能写在 webcat.bbroot.com 上。

CNAME 委托的正确写法
dns-01 要求把 TXT 放在 _acme-challenge.你的域名。如果你不想让签发服务器拿到整个域名的 DNS 权限，可以把这一步委托出去：
规则要点：
1. 这条 CNAME 只写一次，长期不变；每次续期变化的是委托目标那边的 TXT 内容
2. CNAME 不能和其他同名的 A / TXT / CAA 记录共存（DNS 规范限制，同名互斥）
3. 不要写成 TXT 记录，类型必须是 CNAME
4. 值末尾的点表示绝对域名，部分面板会自动补，按面板提示填即可
使用说明
1. 先在有效时长输入框填数字，再点「天 / 月 / 年」，下方会实时显示当前设置与预计到期时间。
2. 点「签发证书」，直接在浏览器本地生成证书与私钥，不校验域名归属、不查任何 DNS 记录。
3. 生成后页面显示域名、签发机构、生效时间与失效时间。签发前需要根证书就绪：点「下载根证书 rootCA.crt」，装进设备信任列表，本站签发的证书才会被系统信任；没装过的设备仍会提示不受信任。
4. 签发后结果区会给出 Nginx 与 Apache 的 HTTPS 配置，复制到服务器并重载即可开启 HTTPS。
5. 传输证书优先用「加密导出」的 .p12（先设口令，至少 6 位），内含证书与私钥，必须口令才能打开，不要明文外发私钥。
5. 证书与私钥全部在本机浏览器生成，不上传服务器，关闭页面即清除。
